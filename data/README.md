# Data Directory Index

This directory is organized by prepared data domain:

- `phenology/`: complete grape phenology observations and phenology-only derived tables.
- `topography/`: Copernicus DEM GLO-30 tiles and derived terrain/background tables.
- `weather/`: complete ERA5-Land daily weather data.
- `gee/`: Google Earth Engine weather extraction indexes and export instructions.

## Phenology

Core complete phenology tables:

- `data/phenology/processed/france_grape_phenology_complete.csv`
  - Complete standardized France TEMPO grape phenology table.
- `data/phenology/processed/germany_grape_phenology_complete.csv`
  - Complete standardized Germany DWD grape phenology table.
- `data/phenology/processed/pep725_selected_countries_grape_phenology_complete.csv`
  - Complete standardized PEP725 grape phenology table for Austria, Slovakia, Spain, and Switzerland.

Prepared 1951+ phenology modeling tables:

- `data/phenology/processed/phenology_observations_1951.csv`
  - Simplified observation-level table.
  - One row per retained phenology observation.
- `data/phenology/processed/phenology_site_year_stage_1951.csv`
  - One row per `site x year x standard BBCH` event.
  - Aggregates duplicate observations using phase-specific rules.

Six-country standardized phenology layer:

- `data/phenology/derived/standardized_bbch/six_country_phenology_bbch_standardized.csv`
  - Standardized BBCH analysis table for France, Germany, Austria, Switzerland, Slovakia, and Spain.
  - Adds harmonized fields such as `bbch_standard`, `bbch_major`, `phenophase_standard`, `phenophase_order`, `bbch_mapping_confidence`, and `bbch_mapping_note`.

Six-country 1951+ base table:

- `data/phenology/derived/base_table/six_country_base_table_1951.csv`
  - Filtered 1951+ six-country observation-level base table.
  - Keeps phenology and station fields only.
  - Does not include weather or DEM variables.

France–Germany exact-stage modeling cohort:

- `data/phenology/derived/modeling/france_germany_four_stage/`
  - Reproducible 1951+ cohort for BBCH 07, 65, 81, and 89.
  - Provides long event, wide site-year, site inventory, stage summary, and
    chronology-anomaly tables.
  - The long table already carries site DEM, official ERA5-Land grid elevation,
    site-minus-grid elevation, terrain, spatial-block, and weather-QC fields.
  - Generated by `src/base_table/build_france_germany_four_stage_dataset.py`.

## Topography

Raw DEM tiles:

- `data/topography/raw/copernicus_dem_glo30/country_tiles/`
  - Copernicus DEM GLO-30 GeoTIFF tiles.
  - Organized by country: `austria/`, `france/`, `germany/`, `slovakia/`, `spain/`, `switzerland/`.
- `data/topography/raw/era5_land_invariant/`
  - Untracked official ECMWF 0.1-degree geopotential and land-sea mask files.
  - Provenance and checksums: `data/topography/metadata/era5_land_invariant.md`.

DEM tile manifest:

- `data/topography/metadata/copernicus_dem_glo30_country_tiles.csv`
  - Tile-level manifest with `country`, `tile_lat`, `tile_lon`, `tile_name`, `url`, `local_path`, `status`, and `size_mb`.

Processed DEM background tables:

- `data/topography/processed/site_region_dem_glo30_background_0p1deg.csv`
  - Coarse 0.1-degree DEM background table for site-region plotting.
  - Fields: `longitude`, `latitude`, `elevation_m`, `tile_lat`, `tile_lon`.
- `data/topography/processed/site_region_dem_glo30_background_0p1deg_top40tiles.csv`
  - Coarse 0.1-degree DEM background subset/extension for the top 40 site-overlap tiles.
  - Fields: `longitude`, `latitude`, `elevation_m`, `tile_lat`, `tile_lon`.
- `data/topography/processed/era5_land_grid_dem_summary.csv`
  - Official ERA5-Land grid elevation plus independent Copernicus GLO-30
    terrain statistics aggregated within each represented 0.1-degree cell.
  - `era5_grid_elevation_m` is model orography; `glo30_grid_*` fields describe
    sub-grid terrain heterogeneity and must not be used as model orography.
- `data/topography/processed/site_era5_land_grid_crosswalk.csv`
  - Site-to-grid crosswalk containing `site_uid`, `era5_grid_id`, 1/2-degree
    spatial blocks, official grid elevation, land fraction, GLO-30 terrain
    variability, and site-minus-grid elevation.
- `data/topography/processed/site_era5_land_grid_country_summary.csv`
  - Country-level site/grid counts, elevation-difference thresholds, coordinate
    stability, source-DEM discrepancies, and coastal-buffer site counts.
- `data/topography/processed/site_era5_land_grid_altitude_band_summary.csv`
  - The same grid-representativeness diagnostics stratified by country and
    site elevation band.

Site-level terrain table:

- `data/phenology/derived/descriptive_phenology/site_topography.csv`
  - Site-level DEM-derived terrain summary joined to phenology sites.
  - Generated by `src/base_table/build_site_topography.py` from the 1951+ base table and local Copernicus tiles.
  - Covers every retained six-country site with `dem_elevation_m`; fields also include `site_uid`, local DEM median/variability, `source_altitude_m`, `altitude_source`, `slope_deg`, `aspect_deg`, northness/eastness, coordinate stability, `terrain_class`, and `elevation_difference_m`.
- `data/phenology/derived/descriptive_phenology/site_topography_country_summary.csv`
  - Country-level DEM coverage and source-versus-DEM elevation audit.
- `data/phenology/derived/descriptive_phenology/site_topography_elevation_discrepancies.csv`
  - Sites where source and Copernicus elevations differ by more than 100 m.

Study-period convention:

- Site overlays and site-driven DEM tile selection use observations from 1951 onward by default.
- Country-scale DEM pixels are static environmental data and are clipped spatially to the six study countries, not temporally.

## Weather

Current per-site files and reuse/download commands are documented in
[`weather/README.md`](weather/README.md). They use the explicitly selected
France–Germany site inventory and export `Date,Tmean` (Celsius) to
`data/weather/sites/<site_name>.csv`. The local coverage audit is available;
daily values still require the existing exports or authenticated Earth Engine
access. The historical storage descriptions below are not evidence that those
data files are currently present.

Complete daily weather data:

- `data/weather/processed/era5_land_daily_complete/`
  - Complete ERA5-Land daily weather dataset.
  - Stored as 20 CSV parts named `era5_land_daily_grape_1951_part_00_of_20.csv` through `era5_land_daily_grape_1951_part_19_of_20.csv`.
  - Includes restored station coordinates and filled France coastal/island site-years.

Model-ready daily weather data:

- `data/weather/processed/era5_land_daily_model_ready/`
  - Twenty CSV parts corresponding one-to-one with the complete source-unit
    parts, without overwriting them.
  - Temperatures are in degrees Celsius, precipitation in millimetres,
    pressure in kPa, radiation in MJ m-2 day-1, and wind in m s-1.
  - Tiny negative precipitation caused by floating-point round-off is clamped
    to zero and counted in the QC table.
- `data/weather/processed/qc/weather_site_year_qc.csv`
  - Expected versus actual coverage, missing/duplicate dates, physical checks,
    event-date coverage, and buffer-fill flags for every site-year.
- `data/weather/processed/qc/weather_model_ready_summary.json`
  - Compact processing and QC summary.
- `data/weather/processed/qc/weather_model_ready_units.csv`
  - Unit and conversion dictionary for every normalized weather variable.

Weather variables:

- `temperature_2m`
- `temperature_2m_min`
- `temperature_2m_max`
- `dewpoint_temperature_2m`
- `total_precipitation_sum`
- `surface_pressure`
- `surface_solar_radiation_downwards_sum`
- `u_component_of_wind_10m`
- `v_component_of_wind_10m`

Main join/context fields include:

- `weather_id`, `country`, `source`, `site_id`, `site_name`, `lat`, `lon`, `alt_m`, `year`
- `weather_start_date`, `weather_end_date`, `weather_date`, `weather_year`, `weather_month`, `weather_doy`
- `n_events`, `bbch_list`, `phenophase_list`, `model_tier`
- `weather_fill_method`, `weather_fill_buffer_m`

Merge summary:

- `data/weather/processed/weather_complete_merge_summary.json`
  - Documents total rows, filled records, output part files, and missing-value checks after the complete weather merge.

## GEE Weather Export Inputs

These files support weather data generation but do not contain daily weather values:

- `data/gee/weather_download_index_1951.csv`
  - One row per `site x year`, derived from the 1951+ phenology site-year-stage table.
- `data/gee/weather_download_index_1951_gee_20parts.csv`
  - Same index with `gee_part` and `gee_part_key` fields for 20 split GEE exports.
- `data/gee/gee_era5_download_script.md`
  - Google Earth Engine Code Editor script and manual export instructions.
