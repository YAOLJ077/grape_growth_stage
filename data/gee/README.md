# Google Earth Engine weather export inputs

The current per-site reuse/download workflow is described in
[`../weather/README.md`](../weather/README.md). It reuses daily weather exports
placed here, ignores index-only tables, and downloads remaining gaps when
Earth Engine access is configured. Final files contain only `Date,Tmean` and
are named from each site's `site_name`. The historical indexes below remain
unchanged.

This directory stores the prepared site-year weather extraction indexes and
Google Earth Engine export instructions used to build the complete ERA5-Land
daily weather dataset under `data/weather/processed/era5_land_daily_complete/`.

Files:

- `weather_download_index_1951.csv`: one row per `site_id x year`, derived from `data/phenology/processed/phenology_site_year_stage_1951.csv`.
- `weather_download_index_1951_gee_20parts.csv`: the same index with `gee_part` and `gee_part_key` fields for 20 split Earth Engine exports.
- `gee_era5_download_script.md`: Code Editor script and manual export instructions for ERA5-Land daily weather.

The default weather window is previous-year September 1 to current-year
December 31. These files are indexes and export instructions; they do not store
daily weather values.

## Weather Download Index

Generated by `src/base_table/build_weather_download_index.py`.

Output:

- `weather_download_index_1951.csv`

Each row is one `site_id x year` extracted from `data/phenology/processed/phenology_site_year_stage_1951.csv`.
The default daily weather window is previous-year September 1 to current-year December 31,
which supports both winter chilling and within-year forcing feature construction.

Placeholder fields `download_status`, `weather_source`, and `local_weather_path` are included
for later weather download workflows. No weather values are stored in this index.
