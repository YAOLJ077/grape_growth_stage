# BBCH89 independent endpoint analysis

Generated by `src/modeling/run_predicted_veraison_to_harvest.py`.

- `predicted_veraison_to_bbch89_outer_predictions.parquet`: spatially held-out BBCH89 predictions using cross-fitted/pure-training-region BBCH81 starts.
- `predicted_veraison_to_bbch89_inner_predictions.parquet`: training-region four-fold OOF predictions used for formal method selection.
- `predicted_veraison_to_bbch89_threshold_fits.csv`: fold-specific post-veraison GDD10 thresholds and start coverage.
- `predicted_veraison_to_bbch89_inner_threshold_fits.csv`: training-region fold-specific post-veraison thresholds.
- `common_sample_method_comparison.parquet`: seasonal GDD10 and predicted-veraison GDD10 on identical records and folds.
- `common_sample_method_metrics.csv`: MAE, RMSE, bias, coverage, penalized errors and ±5/±7-day hit rates.
- `run_summary.json`: execution and leakage-control summary.

Training-region BBCH81 starts are produced by four-fold spatial cross-fitting. Spatial test-region starts are predicted by a BBCH81 model fitted only on the current training region. No observed test-region BBCH81 date is used by the operational chain.
