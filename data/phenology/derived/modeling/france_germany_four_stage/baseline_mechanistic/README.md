# Mechanistic baseline outputs

Generated by `src/modeling/run_mechanistic_baselines.py` with `n_jobs=2` and 401 threshold candidates.

- `primary_analysis_event_index.csv`: pooled core+extended primary cohort; tier labels are intentionally absent from the analysis export.
- `nested_cv_threshold_fits.csv`: inner- and outer-training-fold parameter estimates.
- `nested_cv_predictions.parquet`: all inner-validation and outer-test predictions.
- `nested_cv_metrics.csv`: complete-case error, year-end-penalized error and prediction coverage.
- `inner_cv_model_selection.csv`: backward-compatible branch-specific formal ranking based only on training-region out-of-fold predictions.
- `stage_model_selection_metrics.csv`: unified four-metric candidate table with one-SE and selection flags.
- `stage_model_stability.csv`: fold-level MAE, RMSE, bias and coverage QC.
- `stage_model_selection_decisions.csv`: one formal model-temperature decision per stage and spatial test round.
- `stage_model_selection_consensus.csv`: decision frequency across the five rounds.
- `stage_model_final_selection.csv`: frozen study-stage structures, requiring unanimous five-round agreement.
- `formal_selected_model_outer_predictions.parquet`: spatial-test predictions chosen without using spatial-test outcomes.
- `formal_selected_model_outer_metrics.csv`: corresponding spatial-test metrics.
- `selected_model_outer_predictions.parquet`: outer-test predictions from the inner-selected independent-stage model.
- `selected_model_outer_metrics.csv`: corresponding outer-test metrics.
- `run_summary.json`: cohort, work and runtime audit.

An event whose threshold is not reached within the target year is scored at the day after year-end during calibration and model selection, and remains missing in the prediction table so coverage can be reported explicitly. The observed-veraison maturity model uses a conditional subset and is not ranked against full-sample models. The predicted-veraison chain is generated on the full BBCH89 sample and is formally compared with seasonal GDD10 using the same training-region folds.

These are mechanistic baseline results, not final hybrid-model conclusions. In particular, weak maturity/harvest performance should be diagnosed for source, country, management endpoint and temporal structure before residual machine learning is introduced.
