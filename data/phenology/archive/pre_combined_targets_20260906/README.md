# Superseded phenology deliverables

These files preserve the earlier split exports, their validation metadata, the
standalone processing note and the inventory-check notebook. They are historical
snapshots, not inputs to the current paper pipeline.

The active four-stage dataset is `data/phenology/derived/paper_targets/observations.csv`.
The canonical processing procedure is in the repository-root `AGENTS.md`; runnable
processing and independent verification are in `src/phenology/`.

No raw observations, full cleaned inventory, provenance or quarantine records
were removed. Archived files can be copied back when historical inspection is needed.
