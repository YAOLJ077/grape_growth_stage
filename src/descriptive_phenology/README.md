# Descriptive Phenology Figures

This module creates a small set of overview figures from the complete processed
France and Germany grape phenology tables.

Run:

```bash
python src/descriptive_phenology/plot_descriptive_phenology.py
python src/descriptive_phenology/plot_phenology_data_coverage.py
python src/descriptive_phenology/plot_site_topography_overlay.py
```

Six-country extension:

```bash
python src/standardize_bbch_analysis_layer.py
python src/descriptive_phenology/plot_descriptive_phenology_six_countries.py
```

The six-country script combines France TEMPO, Germany DWD, and the standardized
PEP725 extension table for Austria, Switzerland, Slovakia, and Spain. It uses
the derived standard BBCH analysis layer generated by
`src/standardize_bbch_analysis_layer.py`.

Default outputs:

- Figures: `fig/descriptive_phenology/`
- Derived summaries: `data/phenology/derived/descriptive_phenology/`
- Processed topography cache: `data/topography/processed/`

Six-country outputs are written separately under:

- Figures: `fig/descriptive_phenology/six_countries/`
- Derived summaries: `data/phenology/derived/descriptive_phenology/six_countries/`

The script intentionally produces a few combined figures instead of many
single-purpose plots.
